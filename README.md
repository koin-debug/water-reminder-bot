# 💧 Water Reminder Bot

Telegram-бот для контроля водного баланса. Помогает не забывать пить воду в течение дня, ведёт статистику выпитых стаканов и позволяет настраивать индивидуальное расписание уведомлений.

## ✨ Основные возможности

* **Напоминания по расписанию:** отправка уведомлений в заданное время с интерактивной кнопкой подтверждения («Выпил стакан ✅»).
* **Учёт прогресса:** подсчёт выпитых стаканов за день с автоматическим обнулением в полночь.
* **Гибкая настройка времени:** изменение графика напоминаний прямо в диалоге с ботом.
* **Надёжное хранение данных:** автоматическое сохранение настроек, счётчика и статуса последних уведомлений в `user_data.json` (защита от потери данных и дубликатов при перезапуске).
* **Факты о воде:** случайные познавательные факты по нажатию кнопки в меню.

## 🛠 Стек технологий

* **Python 3.14**
* **pyTelegramBotAPI (`telebot`)** — взаимодействие с Telegram Bot API
* **threading, json, datetime, pathlib** — стандартная библиотека Python

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/koin-debug/water-reminder-bot.git](https://github.com/koin-debug/water-reminder-bot.git)
   cd water-reminder-bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте токен бота:**
   Создайте в корне проекта файл `config.py` и добавьте в него токен, полученный от `@BotFather`:
   ```python
   BOT_TOKEN = "ваш_токен_бота"
   ```

5. **Запустите бота:**
   ```bash
   python reminder_bot.py
   ```
